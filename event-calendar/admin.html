Event Data Editor

Internal tool — not linked from the public site. Generates valid JSON so you don't have to hand-edit it.
This tool doesn't save anything by itself. It just builds the correct data/events.json content for you — you still need to copy the result and paste it into that file on GitHub, then commit.
1. Edit rows below, or click "Add event" for a new one.
2. Click Generate JSON at the bottom.
3. Click Publish directly to GitHub (needs a token, set up below) — or use Copy to clipboard and paste into data/events.json on GitHub yourself.
GitHub token (kept only in this browser's storage, never sent anywhere except GitHub's API)

Needs a fine-grained token scoped to just this repo with Contents: Read and write — the same kind used for the approval-email flow. If you're on a shared or public computer, click Forget when done.
